# TaskFlow — Project Management Tool

A responsive project management dashboard built with HTML, CSS and vanilla JavaScript.

## Features
- Responsive layout for desktop, tablet and mobile
- Create, edit, complete and delete tasks
- Create projects and track completion progress
- Search tasks and filter by status
- Saves projects and tasks in the browser using localStorage

## Run locally
1. Extract the ZIP folder.
2. Open the `TaskFlow` folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the Live Server extension in VS Code.

No backend or installation is required. Data is stored in the browser on the device being used.
